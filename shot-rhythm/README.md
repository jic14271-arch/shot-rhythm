# 镜头节奏 · 本地网页应用

上传一段完整视频，自动检测镜头剪切点，并生成按实际镜头时长等比例绘制的节奏时间轴。短于中位数的镜头为红色，越短越深；长于中位数的镜头为蓝色，越长越深；恰好等于中位数时使用浅灰色。

## 启动

需要 Node.js 20 或更高版本，以及 FFmpeg（包含 `ffprobe`）。确保 `node`、`ffmpeg`、`ffprobe` 都能在命令行运行。

在此文件夹双击 `start.bat`，或打开终端运行：

```powershell
node server.js
```

然后在浏览器打开 **http://127.0.0.1:4317**。关闭终端即可停止服务。无需安装 npm 依赖，也不需要连接网络。

**使用期间请保持启动窗口打开。** 如果浏览器提示无法连接本地分析程序，重新双击 `start.bat`，然后在页面点击“重试分析”；视频文件无需重新选择。

## 使用

1. 在页面选择或拖入视频，等待镜头分析完成。
2. 点击时间轴色块查看镜头；通过播放位置或输入秒数添加切点，也可以修改或删除选中镜头的起止切点。
3. 按需放大时间轴，或导出 SVG、PNG 图片和 CSV 镜头数据。
4. 如果误判较多，可调整下方检测阈值后重新分析。重新分析会替换手工校正的切点。

视频会在本机临时目录中用于 FFmpeg 分析，分析后自动删除；页面中的视频预览直接读取你选择的本地文件。程序仅监听 `127.0.0.1`。部分视频编码可能无法在浏览器中预览，但只要 FFmpeg 可读取，仍可分析并通过秒数校正切点。

自动切点检测对快速运动、闪白和渐变转场可能有漏检或误检，建议导出前检查关键位置。时间轴宽度严格对应时长；极短镜头在总览中可能很窄，可以使用放大滑块查看。
